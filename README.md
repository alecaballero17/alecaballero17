## Sobre mí

Soy estudiante de Ingeniería Informática en la UAGRM y desarrollador orientado a crear productos completos: desde el modelado de datos y las APIs hasta interfaces web, móviles y experiencias interactivas. Me interesa especialmente convertir problemas reales en software útil, mantenible y con buena experiencia de uso.

- Construyo aplicaciones full stack, sistemas de información y herramientas de automatización.
- Trabajo con datos geográficos, visualización 3D, APIs y funcionalidades de IA.
- Me gusta combinar una arquitectura clara con interfaces que hagan la tecnología más fácil de usar.
